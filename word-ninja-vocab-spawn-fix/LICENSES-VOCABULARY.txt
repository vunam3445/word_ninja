WORD NINJA — VOCABULARY DATA ATTRIBUTION

1) Oxford 3000 CEFR list
Source: https://github.com/Kolia951/The_Oxford_3000_CEFR
The repository publishes the Oxford 3000 list grouped into A1, A2, B1 and B2 in package.txt.
Please review the upstream repository's LICENSE and source notes before redistributing the vocabulary data.

2) English–Vietnamese dictionary enrichment (optional local import)
Source: https://github.com/skypediacode/english-vietnamese-dictionary
Primary source attribution in that repository references the MinhQND Dictionary and other open linguistic resources.
The dictionary dataset is licensed CC BY-SA 4.0 according to the repository's published ATTRIBUTION.md. Any redistributed derivative data must retain the required attribution and comply with the share-alike terms. The full 42 MB SQLite dictionary is not bundled in this Word Ninja package; the import script downloads it locally when requested and imports matching definitions into the user's PostgreSQL database.

Recommended attribution to display in game credits:
Oxford 3000 CEFR word list: Kolia951/The_Oxford_3000_CEFR (see upstream source for license/source details).
English–Vietnamese meanings and IPA, where imported: Skypedia, based on the MinhQND Dictionary and upstream open-source linguistic resources; licensed CC BY-SA 4.0. https://github.com/skypediacode/english-vietnamese-dictionary

Word Ninja must not invent Vietnamese meanings for unmatched entries. Words without a verified Vietnamese meaning are stored as not battle-ready until enriched/verified.

3) Android offline dictionary package
The Android APK workflow downloads `dictionary_en_vi.db` and `ATTRIBUTION.md` from:
https://github.com/skypediacode/english-vietnamese-dictionary

The database and repository attribution state CC BY-SA 4.0. The Android build includes the upstream attribution document alongside the database. Preserve the upstream attribution and ShareAlike requirements when redistributing the APK or a modified dictionary. The SQLite database is downloaded during the GitHub Actions build; it is not stored in this source ZIP.
